# Memória do projeto L2 Morbius

- Base: Lineage 2 Interlude / Chronicle 5.
- O servidor usa XML em `dist/game/data/stats` para itens, skills e armorsets.
- Os itens premium usam IDs customizados a partir de 10000.
- Top Donation: cópias do Apella Heavy, Light e Robe, mantendo a aparência Apella e usando bônus superiores aos sets S-Grade.
- Tattoos especiais são itens equipáveis no slot `underwear`: Tattoo of the Arcane e Tattoo of the Berserker.
- Farm zone será criada posteriormente usando mobs editados.
